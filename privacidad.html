2. Datos y finalidad

Si envías el formulario, se tratarán el nombre, teléfono, localidad, servicio solicitado, mensaje y, si decides adjuntarlas, fotografías. Se usarán únicamente para estudiar la consulta, contactar contigo y preparar o gestionar el presupuesto solicitado.

3. Base jurídica

La base prevista es la aplicación de medidas precontractuales solicitadas por la persona interesada y, cuando corresponda, su consentimiento. Antes de publicar debe confirmarse la base adecuada para cada tratamiento real.

4. Conservación

PLAZO PENDIENTE: deberá definirse un plazo proporcionado para consultas no contratadas y otro para documentación contractual o fiscal sujeta a obligaciones legales.

5. Destinatarios y proveedores

Las solicitudes del formulario se tramitan mediante FormSubmit para remitirlas al correo de contacto configurado. Antes de utilizar esta web como sitio comercial definitivo deberán revisarse sus condiciones, formalizarse los proveedores necesarios e identificarse el alojamiento y cualquier posible transferencia internacional.

6. Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad mediante , acreditando tu identidad cuando sea necesario. También puedes reclamar ante la Agencia Española de Protección de Datos.

7. Seguridad y veracidad

Se aplicarán medidas razonables para proteger los datos. La persona usuaria debe facilitar información veraz y evitar adjuntar fotografías con datos de terceras personas que no sean necesarios.
